# Sara Vieira | Website completo

Site Nuxt 3 + Vue, responsivo, com identidade editorial em café, âmbar e creme.

## Seções
Hero preservada, apresentação, psicanálise clínica e hipnose, diferenciais, jornada, formatos online/presencial, perguntas frequentes, CTA de WhatsApp e rodapé.

## Desenvolvimento
```bash
npm install
npm run dev
npm run build
```

## Configuração na Vercel
Framework **Nuxt.js**; Node.js 22.x; build automático conectado ao GitHub. O arquivo original da Hero está salvo em `backups/hero-v1.html`.
