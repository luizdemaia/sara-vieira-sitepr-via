# Sara Vieira — Hero editorial
Prévia Nuxt 3 / Vue 3 / TypeScript / Tailwind. Escopo: Hero desktop e mobile.
## Desenvolvimento
npm install
npm run dev
## Build
npm run build
Vercel: root directory nova-hero; framework Nuxt.js; build npm run build.
## Pendências
- Substituir public/images/sara.png pelo retrato JPG anexado mais recentemente. O PNG provisório é o retrato existente no repositório (1122 × 1402 informado na versão anterior).
- Nota 5,0 vem exclusivamente do print fornecido; confirmar no Google antes da publicação definitiva.
- Cidade, endereço, público, domínio e credenciais adicionais não confirmados.
- Prévia bloqueada para indexação. Configurar canonical, sitemap e SEO de produção quando domínio e conteúdo final forem aprovados.
